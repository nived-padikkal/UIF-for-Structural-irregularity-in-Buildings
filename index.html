Unified Identification Factor

(A single parameter for all structural irregularities)

Home Contact
During an earthquake, failure starts from the weakest points that arise due to the irregularities in the structure. The Unified Identification Factor (UIF) is a simplified approach for the identification and quantification of structural irregularity in buildings. The aim is to reduce the complexity associated with the numerous parameters and criteria for the seismic analysis and design of irregular buildings.
A Python code has been developed to integrate the calculation of UIF in the structural analysis software ETABS. The final output of the code is an interactive 3D model which displays the UIF values for different columns of the building.
Steps:
  1. Open ETABS model and run analysis for 1.5 (DL + LL) combination
  2. Run Python code
