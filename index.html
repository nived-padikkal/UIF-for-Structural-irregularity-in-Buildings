Unified Identification Factor

(A single parameter for all structural irregularities)

Home Contact
During an earthquake, failure starts at the weakest points caused by structural irregularities. Seismic design standards worldwide emphasise the importance of avoiding building irregularities through careful architectural planning and structural configurations. However, the complexity of codal guidelines and frequent revisions/amendments often tempt designers to ignore the irregularity checks during the design stage.
The Unified Identification Factor (UIF) is a simplified approach for the identification and quantification of structural irregularity in buildings. The aim is to reduce the complexity associated with the numerous parameters and criteria for the seismic analysis and design of irregular buildings.
Further details of UIF can be found in the published paper, https://doi.org/10.12989/smm.2024.11.2.101.
An algorithm has been developed in Python to integrate UIF into the structural analysis software ETABS. The final output of the code is an interactive 3D plot that displays the UIF values for different columns and highlights the columns with the maximum and minimum UIF. A downloadable Excel facilitates further analysis of the axial forces, tributary areas and UIF values.
Steps to follow:
  1. Open ETABS model and run analysis for the 1.5 (DL + SDL + LL) combination
  2. Run the Python code
